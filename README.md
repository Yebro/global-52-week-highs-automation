# 52주 신고가 트래커

한국 KOSPI·KOSDAQ은 시가총액 제한 없이, 그 외 시장은 원화 환산 시가총액 3,000억원 이상 종목을 대상으로 최근 완료 거래일 종가가 직전 최대 251거래일 종가 최고치 이상인지 계산합니다. 시가총액 미확인 종목은 제외합니다. 상장 52주 미만 종목은 상장 이후 데이터로 계산하며 최소 20거래일이 필요합니다.

돌파 후 수익률은 2년 가격 이력으로 각 거래일의 52주 신고가 여부를 판정한 뒤, 최신 종가를 최근 365일 안에서 처음 52주 신고가를 기록한 날의 종가와 비교합니다. 신고가 흐름이 중간에 끊겨도 기준일을 리셋하지 않아 최근 1년의 추세 수익률을 보여줍니다.

대시보드의 수익률 옆 경과일수는 최초 신고가 기준일부터 최신 종가 기준일까지의 달력일수입니다.

## 시장 범위

- 미국: NASDAQ 전체 + S&P 500, 티커 중복 제거
- 한국: KOSPI + KOSDAQ
- 일본: TSE
- 중국: SSE + SZSE
- 대만: TWSE + TPEx
- 홍콩: HKEX

## 갱신

PowerShell에서 다음 명령을 실행합니다.

```powershell
.\refresh.ps1
```

초기 설치가 필요한 경우:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 클라우드 자동 갱신

GitHub Actions는 한국시간 기준 평일 16:05와 다음 날 08:05에 첫 실행됩니다. GitHub 예약 지연에 대비해 16:20·16:35·16:50 및 08:20·08:35·08:50에도 예비 실행을 요청하며, 첫 성공 이후의 예비 실행은 수집과 배포를 건너뜁니다. 16시 실행은 한국 또는 일본 시장의 당일 종가가 확인될 때만, 08시 실행은 미국 시장의 전일 종가가 확인될 때만 새 대시보드를 배포합니다. 따라서 휴장일은 자동으로 건너뛰고, 아시아와 미국 시장이 모두 열리면 하루 두 번 갱신됩니다.

배포 성공 알림은 저장소의 Actions 비밀값 `TELEGRAM_BOT_TOKEN`과 `TELEGRAM_CHAT_ID`가 모두 설정된 경우 텔레그램으로 전송됩니다. 토큰은 코드나 대화에 기록하지 않습니다.

수동 실행은 GitHub의 Actions 화면에서 `Update 52-week highs dashboard`를 선택해 실행할 수 있습니다.

## 결과

- `dashboard.html`: 실제 스냅샷을 포함한 로컬 대시보드
- `data/latest.json`: 대시보드용 집계와 신고가 종목
- `data/screened.csv`: 가격 수집에 성공한 전체 종목과 판정 결과
- `data/universe.csv`: 시장별 종목·섹터 마스터

시가총액은 한국은 KRX 원화 시가총액, 미국·일본·중국·홍콩은 현지통화 시가총액, 대만은 발행주식 수와 최근 종가를 이용합니다. 해외 시가총액은 수집 시점의 원화 환율로 환산합니다.

종목 목록은 FinanceDataReader/Naver, S&P 500 목록, TWSE 및 TPEx OpenAPI를 이용합니다. 가격은 Yahoo Finance의 일별 종가를 사용합니다. 무료 데이터 소스의 심볼 미지원이나 응답 누락은 시장별 수집률에 표시됩니다.
